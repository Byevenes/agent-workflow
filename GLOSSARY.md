# Glossary

- **Workflow stack**: this repo plus the user-level installs it links to. Skills, agents, MCP templates, OpenCode, and Cursor.
- **Skill**: a `SKILL.md` instruction contract the agent loads. Not a compiled program.
- **Agent**: a markdown role. It can delegate to another agent.
- **Subagent**: an agent spawned for one slice, then finished. It does not own the conversation.
- **Outer loop**: Grok bots that read tasks and hand them inward. They do not replace the local sessions.
- **Issue tracker**: for this repo, markdown files under `.scratch/`. Not the host's issue product.
- **zStack**: the whole flow, from intake to retro (`skills/zstack`). `route-work` is its alias until 2026-12-01.
- **zIGL**: the router role that classifies, plans and checks (`agents/zigl.md`, and the zstack skill itself).
- **zNinja**: the implementer subagent (`agents/zninja.md`).
- **zSensei**: the reviewer subagent (`agents/zsensei.md`).
- **zHunter, zGuard**: reserved names, no role yet.
- **Clients root**: where client repos live. Non-empty `CLIENTS_ROOT`, otherwise `clients_root` in the client map, otherwise `$HOME/Clients`.
- **Client map**: local untracked toml at `ZSTACK_CLIENTS_TOML`, or `~/.config/zstack/clients.toml` when that variable is unset. Never commit it.
- **Token budget**: 150_000 tokens, one session before the agent degrades.
- **Holgura**: the slack factor on a token estimate. The estimator names it. This repo sets no default.
- **Ticket count**: how many token-budget sessions the estimate covers once holgura is applied.
- **Printed size**: the size on the classification line, after Classify applies risk and the token budget.
- **Repo-root path**: an inline file citation from the repository root, such as `src/Foo/Bar.cs`. `scripts/check-repo-paths.sh` rejects a bare name that is not at that root, a working-directory prefix, and a machine-absolute path.
- **In-module caller**: a symbol in the same module as a changed symbol that reaches it by calls that stay in that module. Private symbols count. The changed symbol is not its own caller. `scripts/blast-radius-callers.sh` lists them and fails when a report misses one.
- **Env-known failure**: a HEAD failure whose id and detail also fail on the base branch. It does not block slice close. `scripts/classify-test-failures.sh` is the only thing that may apply this label.
- **Real failure**: a HEAD failure that is new, different from the base branch, or has no base result. It blocks slice close.
