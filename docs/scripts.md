# Scripts

Scripts carry no comments (decision 20: only issue or RFC links and license lines are allowed). What each one does:

- `scripts/link.sh`: points the user-level Cursor and OpenCode folders at this repo, removes old route-work links that point here, and sets `core.hooksPath` to `.githooks`. It never replaces a regular file; directories under `~/.agents/skills` are added only when the name is absent. Matt skills under `~/.agents/skills` are mirrored into Cursor and OpenCode; pstack skills from the Cursor plugin cache go into OpenCode, as `pstack-<name>` when the plain name is taken.
- `scripts/setup-check.sh`: reports whether the local setup resolves, whether the `zgrill`, `zspec` and `ztickets` wrappers and Matt's skills they read are present, whether `tdd` is model-invocable, and the optional MCP env vars (not failures). Never prints secret values. For each git repo under the clients root it appends the local artifact lines `.scratch/` and `.atl/` to that repo's `info/exclude` when the exact line is missing, creates the file when it is absent, leaves every other line in place, and is safe to run again. The `local-exclude` line counts repos that have both entries. It does not edit `.gitignore`, add a tracked config file, or install a hook.
- `scripts/route-audit.sh [project-filter] [days]`: retro counts from Cursor transcripts under `~/.cursor/projects` (zstack or route-work invoked, zninja or implementer launched, poteto-mode loaded by zninja, inline edits with and without a stated reason). Counts only.
- `scripts/mcp-gitlab.sh`, `scripts/mcp-postgres.sh`: start those MCP servers; the token or URL stays in the environment.
- `scripts/check-delivery-note.sh <note>`: exits 0 when a client delivery note has no internal mention, and exits 1 when it does. Patterns, case-insensitive: tool and agent names (`zstack`, `zninja`, `zsensei`, `zigl`, `zgrill`, `zspec`, `ztickets`, `zretro`, `poteto-mode`, `poteto`, `opencode`, `obsidian`, `agent-workflow`), model prefixes (`grok-`, `gpt-`, `claude-`, `sonnet`), the words `cursor`, `kdb` and `zpr`, paths (a leading `~/`, `/Users/`, `/home/`, `.scratch/`, `.atl/`, `.cursor/`), and the author marker `BORRAR ANTES DE ENVIAR`. The script builds the `~/` prefix with `printf` so the source contains no quoted tilde. A URL that contains `/home/`, the English word "cursor", or "sonnet" also fails. The template is `docs/examples/nota-de-entrega.md`. Fixtures live in `docs/examples/delivery-note-fixtures/`.
- `scripts/check-repo-paths.sh <markdown> <repo-root>`: exits 0 when every file citation resolves from that root. A citation is inline code outside a fence, with a file extension that starts with a letter or with a trailing slash. A machine-absolute citation (a leading `/`, a leading tilde, or a drive letter) fails without a disk lookup. A citation with a backslash, an empty segment, `.`, or `..` fails as not a repo-root path. Any other citation must exist under `<repo-root>`. The script builds the tilde with `printf` so the source has no quoted tilde. Fixtures live in `docs/examples/repo-path-fixtures/`. `scripts/check.sh` runs the clean fixture and requires the dirty fixture to name each bad citation and its reason.
- `scripts/check.sh`: the repo's automatic barrier. Runs in `.githooks/pre-commit` (after the main-branch and staged-secret guards) and CI. There is no pre-push hook: CI runs the same check and GitHub protects `main`.
